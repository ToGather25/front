## CSV 명세 확인 결과 (226행 이후, 업데이트된 CSV)

상단 탭 네비게이션: "예배순서 / 말씀 / 공지 / 헌금 / 기도제목 / 섬기는 분들" — 기본 진입 시 '예배순서' 활성화, 탭 전환은 페이지 이동 없이 콘텐츠만 교체.

각 탭 상세:
- **예배순서**: `serviceSession`(1부/2부), `orderItems[]`(순서명/담당자/찬송번호 등). 1부/2부 토글 버튼, 선택된 부의 순서를 번호/순서명/담당(찬송,성경구절) 3열로 표시, 설교·성경봉독 항목은 accent 강조, 상단에 예배 시간·장소 표기.
- **말씀**: `sermonTitle`(설교 제목), `scripture`(본문 말씀), 옵션 `sermonOutline[]`(설교 개요). 제목/본문 참조(예: "로마서 2장 27절") 표기, 본문 말씀 옆 좋아요 버튼(누르면 "성경활동의 좋아요에 추가"), 핵심 본문을 인용 블록(좌측 강조 바)으로 표시, 설교 개요는 옵션(미입력 시 영역 비표시).
- **공지**: `notices[]`(제목/내용/날짜/태그: 행사·행사아님). 카드 형태(날짜/제목/요약), 태그별 카드 색 구분, "행사" 태그면 상세보기 버튼+탭 시 행사 상세로 이동. 공지 없을 시 "등록된 공지가 없습니다".
- **헌금**: `bankAccount`(은행명/계좌번호/예금주), 옵션 `qrCodeUrl`. 계좌이체 카드(탭 시 클립보드 복사), 하단에 연말정산 헌금 영수증 안내 문구, 옵션으로 QR코드 카드(스캔 시 헌금 페이지 연결).
- **기도제목**: `prayers[]`(기도 제목/부제목·대상/옵션 카테고리: 사역·병중·선교·소그룹 등). 카테고리 이모지(사역🙏/병중❤️‍🩹/선교🌍/소그룹🏠)+제목+부제목 두 줄 구성. 미등록 시 빈 화면 대신 "이번 주 기도제목을 준비 중입니다".
- **섬기는 분들**: `ministryRoles[]`(역할명/담당자명). 역할 아이콘/역할명/담당자명 3열, 1부·2부 담당자가 다르면 이름 옆에 "(1부)"/"(2부)" 표시(예: "일렉: 임예원(1부), 임예빈(2부)").

## 코드 탐색 결과

`src/pages/Jubo/Jubo.jsx`(732줄)는 **전통 종이 주보를 그대로 재현한 9탭**(표지/예배/소식/봉사/예물/후원/구역/섬기는 분들/오시는 길)으로, A4 인쇄 CSS까지 갖춘 "인쇄 대체" 목적의 구현이다. 새 CSV의 6탭과는 거의 겹치지 않는다:
- 겹치는 개념: "예배"↔"예배순서"(현재는 5개 예배 종류 사이드바 선택 방식, CSV는 1부/2부 토글 방식으로 다름), "섬기는 분들"↔"섬기는 분들"(현재는 직분별 그룹 리스트+교적부 링크, CSV는 역할별 3열+1부/2부 표시로 다름).
- CSV에 없는 기존 탭: 표지, 소식, 봉사, 예물, 후원, 구역, 오시는 길.
- 기존에 없는 CSV 신규 탭: 말씀, 헌금, 기도제목.

**사용자 확인(2026-08-11)**: 기존 9탭은 내용·구조를 전혀 바꾸지 않고 그대로 유지한다. CSV의 신규 콘텐츠(말씀/헌금/기도제목)만 추가 탭으로 넣는다 — "예배"/"섬기는 분들"의 기존 구조를 CSV 방식으로 다시 만들지 않는다(중복·혼란 방지).

`src/services/juboService.js`+`src/data/dummy/jubo.js`는 `getWorshipOrder`/`getMinisters`/`getOffering` 등 API-ready 함수를 정의하고 있지만 **`Jubo.jsx`가 실제로 import하지 않는 죽은 코드**다(대신 정적 `jubo.config.js`를 직접 읽음). 이번 사이클은 기존 9탭을 "그대로 유지"하기로 확정했으므로 이 죽은 코드도 건드리지 않는다 — 발견 사항으로만 기록.

**좋아요 연동 확인**: CSV는 말씀 탭의 좋아요 버튼이 "성경활동의 좋아요에 추가"되길 요구하지만, 실제 `BibleRead.jsx`의 `savedVerses` 상태는 `useState({})`로 그 페이지 안에서만 존재하는 세션 상태이며 localStorage나 공유 스토어에 저장되지 않는다(새로고침하면 사라짐). 페이지 간 공유는 별도의 아키텍처 작업(상태를 localStorage로 승격 + `BibleRead.jsx` 수정)이 필요해 이번 사이클 범위를 벗어난다. **사용자 확인(2026-08-11)**: 말씀 탭의 좋아요는 주보 탭 내부에서만 동작하는 로컬 토글로 구현하고, 성경읽기와의 실제 연동은 이번 사이클에서 제외한다.

`Jubo.jsx`에는 `/교적부`처럼 인증이 필요한 개인정보가 없다(공개 교회 정보 페이지) — 로그인 가드는 이번 사이클과 무관하다.

**사용자 확인(2026-08-11)**: 12탭(기존 9+신규 3)이 될 예정이라 탭별 컴포넌트로 분리한다. 기존 9탭은 **로직·마크업·문구를 절대 바꾸지 않고 그대로 옮긴다**(성경쓰기·마이페이지 사이클과 동일한 순수 리팩터링 원칙).

```
src/pages/Jubo/Jubo.jsx        — 얇은 부모: 탭 전환(activeTab, URL 쿼리 파라미터 유지) + 인쇄 시 전체 탭 순차 렌더
src/components/jubo/
  ├── shared.jsx                — JuboPage(페이지 래퍼+인쇄 CSS 연동), SectionTitle (기존 그대로 이동)
  ├── Cover.jsx                 — 표지 (기존 그대로 이동)
  ├── Worship.jsx                — 예배 (기존 그대로 이동)
  ├── News.jsx                   — 소식 (기존 그대로 이동)
  ├── Service.jsx                 — 봉사 (기존 그대로 이동)
  ├── Offering.jsx                — 예물 (기존 그대로 이동)
  ├── Support.jsx                 — 후원 (기존 그대로 이동)
  ├── District.jsx                — 구역 (기존 그대로 이동)
  ├── Ministers.jsx                — 섬기는 분들 (기존 그대로 이동)
  ├── Direction.jsx                — 오시는 길 (기존 그대로 이동)
  ├── Sermon.jsx                   — 신규: 말씀
```

`Jubo.jsx`의 `TABS` 배열에 "말씀"/"헌금"/"기도제목"을 기존 9개 뒤에 추가한다. `renderTab`/인쇄용 전체렌더 두 곳 모두에 신규 3개 컴포넌트를 연결한다(신규 탭도 인쇄 시 함께 출력되어 기존 인쇄 동작과 일관성을 유지).

### 신규 3탭 구현

**`jubo.config.js`에 신규 섹션 추가**(기존 9탭과 동일하게 정적 config 패턴 유지):
- `sermon: { title, scripture, outline: [] }` — `outline`이 빈 배열이면 개요 영역 비표시(CSV 예외처리 그대로).
- `giving: { bankAccount: { bank, accountNumber, holder }, qrCodeUrl: null }` — `qrCodeUrl`이 없으면 QR 카드 비표시.
- `prayerTopics: []` — 배열이 비어있으면 "이번 주 기도제목을 준비 중입니다" 빈 상태 표시(CSV 예외처리 그대로).

**`Sermon.jsx`(말씀)**: 설교 제목 + 본문 말씀 참조 표기, 본문 텍스트는 좌측 강조 바가 있는 인용 블록으로 표시. 옆에 하트 아이콘 좋아요 버튼 — `useState(false)`로 주보 탭 내부에서만 토글(성경읽기 연동 없음, 새로고침 시 초기화되는 게 정상 동작). `outline.length > 0`일 때만 설교 개요 리스트 표시.

**`Giving.jsx`(헌금)**: 계좌이체 카드(은행명/계좌번호/예금주)를 탭하면 `navigator.clipboard.writeText`로 계좌번호 복사(`Register.jsx`의 기존 클립보드 복사 패턴 재사용, try/catch로 미지원 환경 방어 + 복사 완료 피드백). `qrCodeUrl`이 있을 때만 QR 카드 추가 표시. 하단에 연말정산 헌금 영수증 안내 고정 문구.

**`PrayerTopics.jsx`(기도제목)**: `CATEGORY_EMOJI = { 사역: "🙏", 병중: "❤️‍🩹", 선교: "🌍", 소그룹: "🏠" }` 매핑으로 카테고리 이모지 표시(카테고리 없으면 이모지 생략). 각 항목은 이모지(옵션)/제목/부제목 두 줄 구성. `prayerTopics.length === 0`이면 빈 상태 문구.
